# Ayaan — Portfolio

A cinematic storybook portfolio for **Shaik Mohammad Murtuzaa Ayaan** — final-year
Computer Science student at KHIT, Guntur (Java · Android · Full-Stack Web).

Built with **HTML + CSS + vanilla JS**, animated with **GSAP + ScrollTrigger** and
smooth scrolling via **Lenis**. Each section is a full-viewport illustrated scene
with layered parallax, cinematic cross-dissolves and drifting ambience.

## Run locally
Just open `index.html` in a browser (needs internet for the GSAP/Lenis/font CDNs).

## Deploy
Static site — **no build step**.
- **Publish directory:** repository root (`.`)
- **Build command:** none

Structure:
```
index.html     — markup + inline-SVG scene layers
styles.css     — design system, responsive, reduced-motion
main.js        — GSAP/ScrollTrigger/Lenis animation
assets/        — resume.pdf + artwork notes
```
